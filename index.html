Database Online & Keamanan

Database engine lokal (localStorage) berperan sebagai server online: indikator koneksi, jam sinkronisasi per-tulisan, dan realtime antar-tab via BroadcastChannel. Skema: students sessions answers warnings activity audit monitors exams questions.

ATURAN ANTI-KELUAR
visibilitychange + pagehide mendeteksi keluar tab / tutup web — sesi langsung finalisasi BANNED di server sebelum halaman mati
Alarm: sirine Web Audio + suara Text-to-Speech id-ID "Kamu keluar dari ujian. Otomatis gabisa ikut ujian lagi."
Pemantau menerima event STUDENT_EXIT realtime + alarm, status berubah merah
Produksi: deteksi sama di server via WebSocket disconnect + token sesi, penalti diputuskan server-side
